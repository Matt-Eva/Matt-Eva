# Matt Eva

Hello there! I'm Matt. I'm a programmer, writer, and former educator.

I started programming about 5 years ago, driven by a desire to build my own publishing platform for writers. That drive has fueled my learning, and has served as the foundation for much tinkering and many deep dives - NoSQL databases, systems architecture and design, scalability, various language paradigms (and tradeoffs), and, of course, the pragmatic lessons that all programmers must learn, namely reliability, maintainability, and extensibility.

I'm currently building the platform with Go as my primary backend (the web frontend is powered by the Go `html/template` package, along with js and css), and react-native and electron as my mobile / desktop frontends, respectively. If you want to read more about the rest of the tech behind the project and learn a little bit about its architecture and conventions, <a href="https://github.com/Matt-Eva/freecreate-go-server">check out the repo</a>! 

I also still love to write and teach. As someone who is largely self-taught, I'm always looking to help demystify technical concepts and connect people with useful tools and ideas. For me, learning and teaching are two sides of the same coin - when I'm doing one, I'll want to do the other.

When I'm not coding, writing, or teaching, you can find me playing music, wandering over hills and under trees, reading, nerding out, and learning new things. I'm always interested in new opportunities and meeting new people, so if I seem like someone you'd like to connect with please reach out!

Happy coding!
